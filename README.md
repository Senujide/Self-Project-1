# Self-Project-1
Customer segmentation and sales analysis using Python and Power BI with interactive dashboards and business insights.

📊 Customer Segmentation & Sales Analysis

Power BI & Python | Self Project

📌 Project Overview

This self-project analyzes retail transaction data to understand customer purchasing behavior and segment customers into meaningful groups. The project combines Python-based data analysis and modeling with Power BI interactive dashboards to generate actionable business insights.

The analysis focuses on identifying repeat customers, high-value customers, and purchasing patterns that support data-driven marketing and customer retention strategies.

🎯 Project Objectives

Analyze customer purchasing behavior using transactional data

Identify repeat and high-value customers

Segment customers based on sales and frequency patterns

Visualize insights using interactive Power BI dashboards

Support data-driven decision-making

📂 Dataset Description

The dataset contains retail transaction-level data including:

Customer ID

Invoice Number

Product Quantity

Unit Price

Transaction Date

Sales Value

The raw dataset required cleaning and preprocessing before analysis.

🧹 Data Cleaning & Preprocessing

Data preparation was performed using Python (Jupyter Notebook).

Steps included:

Removing missing and invalid records

Excluding cancelled and negative transactions

Creating derived variables such as total sales and purchase frequency

Converting date fields for time-based analysis

Standardizing features for customer segmentation

These steps ensured data quality and reliability for analysis.

📈 Exploratory Data Analysis (EDA)

EDA was conducted to:

Identify sales trends over time

Analyze customer purchase frequency

Understand repeat customer behavior

Examine revenue contribution by customer groups

Insights from EDA guided the customer segmentation process.

🧠 Customer Segmentation Methodology

Customer segmentation was performed using clustering techniques in Python.

Features used:

Total Sales

Purchase Frequency

Average Order Value

Approach:

Feature scaling

Clustering model implementation

Interpretation and labeling of customer segments

The resulting segments represent distinct customer behavior groups such as high-value customers, loyal repeat customers, low spenders, and at-risk customers.
